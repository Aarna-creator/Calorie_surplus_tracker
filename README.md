# Calorie Surplus Calculator

## About the Project

This is a Python based project made to calculate and understand a person's daily calorie intake in relation to a calorie target.

The user can enter a calorie target and food details. The program processes the entered information and gives the total calories and the difference between the target and the calories entered.

The main aim of this project is to apply basic Python concepts such as functions, modules, input handling, calculations, conditional statements and error handling in a small real-life type application.

## Main Features

- Takes calorie target as input
- Takes food/calorie information from the user
- Stores and processes the entered food information
- Calculates total calories
- Compares total calories with the target
- Displays the final result in a simple format
- Uses separate Python files for different tasks

## How to Run

1. Install Python on the computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or another Python editor.
4. Run `main.py`.
5. Follow the instructions shown by the program.

## Testing

The program can be tested using different calorie targets and food values.

Some basic test cases are:

| Test | Input | Expected Result |
|---|---|---|
| Normal input | Valid calorie values | Correct total |
| Multiple food items | Several food entries | Sum of entered calories |
| Lower total | Total below target | Program shows that target is not reached |
| Higher total | Total above target | Program shows surplus |
| Equal total | Total equal to target | Program shows target reached |
| Invalid input | Non-numeric value where number is expected | Error handling/input validation |
