# Project Statement - Calorie Surplus Calculator

## Problem Statement

Many people want to keep track of the calories they consume, but doing the calculation manually can be inconvenient. The purpose of this project is to make a simple Python program that takes a calorie target and food information from the user and calculates the total calories.

The program then compares the calculated amount with the target and displays the result.

## Scope of the Project

The project is mainly focused on calorie calculation and comparison. It is a small console-based Python application and is intended for learning and basic calorie tracking.

The current version does not try to replace professional diet or medical advice. It only performs the calculations based on the values entered by the user.

## Target Users

The project can be used by:

- Students learning Python
- People who want a simple way to add calorie values
- Anyone interested in basic calorie tracking

## High-Level Features

1. User input for calorie target
2. Food/calorie input
3. Storage and processing of food information
4. Total calorie calculation
5. Comparison with the calorie target
6. Display of the final result
7. Basic input validation/error handling
